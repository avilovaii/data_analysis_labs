## Задача

Сегментация потребителей леденцов по мотивам потребления.
Определить число кластеров и обосновать выбор; разбить объекты на кластеры;
предложить и обосновать интерпретацию.

## Данные

`data/Леденцы.dat` - результаты опроса. Разделитель `;`.
11 переменных `V1`-`V11` - степень согласия респондента с высказыванием
о причине потребления леденцов (порядковая шкала).

Описание переменных: `data/Леденцы_описание_2.pdf`.

## Цель

Выделить интерпретируемые сегменты потребителей по мотивам потребления и описать их профили.
Сегментирование помогает понять, какие продуктовые свойства и какие сообщения на упаковке
релевантны каждой группе.

## Гипотезы

**Н1. О структуре признаков.** 11 высказываний сводятся к 4 смысловым блокам:

1. V1, V2, V3, V4 — леденцы для освежения дыхания
2. V7, V8 — леденцы как инструмент ментальной настройки
3. V5, V6 — леденцы заменяют сладкое
4. V9, V10, V11 — леденцы помогают улучшить физическое самочувствие

**Н2. О структуре респондентов.** Каждый сегмент характеризуется высокими оценками по одной
группе высказываний и нейтральными по остальным. Ожидается 4 содержательных сегмента,
каждый с пиком по одному блоку, и возможно пятый - нейтральный. Сегмент «свежесть дыхания»
предполагается доминирующим по размеру.

## Результаты

- Число кластеров: **4** (обосновано разрывом высот слияний и кривой силуэта).
- Метод связи: **ward**, метрика - евклидова.
- Решение устойчиво: `ward`, `average` и `complete` дают идентичное разбиение.
